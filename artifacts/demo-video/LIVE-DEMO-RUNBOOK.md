# AURA live demo runbook

## Before judges arrive

1. Start Ollama and warm `qwen3.5:4b-mlx`.
2. Launch `Launch AURA.command`.
3. Open `https://en.wikipedia.org/wiki/Accessibility`.
4. Confirm the page connection says ready.
5. Keep the panel near the top and select **Clear & Calm**.
6. Confirm the network is available for optional cloud refinement.

## 75-second live flow

1. Open with the **Learn Me** screen and say: “Accessibility is not one universal mode.”
2. Show one everyday-comfort question and the completed six-area support combination.
3. Press **Start browsing** and open the prepared page.
4. Press **Scan this page**.
5. Explain that WCAG evidence and personalized AURA Fit are deliberately separate.
6. Press **Make This Mine**.
7. Point out the immediate on-device change, then the semantic refinement.
8. Enter **Show me the search** in Talk to AURA.
9. Show the real search control brought forward.
10. Press **Original**.
11. Close with: “The web should adapt to the person.”

## If cloud refinement is slow

Continue the demo with the local result and say:

> “AURA is local-first. The page changes immediately; cloud semantics are an optional refinement.”

Do not wait silently. The deterministic and on-device experience remains the product.
